# Galaxy Frontier Mobile

Aplicativo mobile do jogo Galaxy Frontier.

## Objetivo
Projeto independente da versão web do Galaxy Frontier, preparado para desenvolvimento Android e futura distribuição em APK/AAB.

## Estrutura inicial
- `app/` — aplicação Android
- `docs/` — documentação do projeto
- `assets/` — recursos visuais
- `README.md` — documentação principal

## Projeto separado
Este repositório não substitui nem altera o projeto web original.
