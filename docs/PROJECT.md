# Galaxy Frontier Mobile — Projeto

## Visão
Criar uma versão mobile independente do Galaxy Frontier, mantendo o projeto web separado.

## Princípios
- Mobile-first
- Controles por toque
- Interface adaptada para telas pequenas
- Código organizado e escalável
- Sem alterar o repositório web
- Preparação para APK e AAB

## Próximas etapas
1. Criar a aplicação Android base.
2. Definir identidade visual.
3. Criar menu inicial.
4. Implementar núcleo do jogo.
5. Adicionar controles de toque.
6. Testar em dispositivos Android.
7. Gerar APK de testes.
8. Preparar AAB para publicação.
