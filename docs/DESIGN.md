# Galaxy Frontier Mobile — Visual Direction

## Produto
Galaxy Frontier Mobile será um jogo espacial mobile independente da versão web.

## Direção visual
- Sci-fi moderno, cinematográfico e acessível.
- Fundo espacial profundo com estrelas, nebulosas e brilho suave.
- Azul elétrico, ciano e violeta como acentos.
- Interfaces com vidro, transparência, bordas suaves e alto contraste.
- Tipografia forte para títulos e simples para informações de jogo.
- Animações curtas e fluidas para dar sensação de tecnologia sem sobrecarregar aparelhos modestos.

## Público
A experiência deve ser fácil de entender para crianças e jovens, mas visualmente sofisticada o suficiente para também agradar jogadores adultos.

## Princípios UX
1. Uma ação principal por tela.
2. Botões grandes e confortáveis para toque.
3. Informação importante sempre visível.
4. Feedback visual imediato para ações.
5. Pouco texto durante o combate.
6. Progressão clara: explorar → combater → ganhar → melhorar → descobrir.

## Protótipo 0.1
O primeiro protótipo implementa:
- tela inicial;
- identidade visual;
- navegação para a tela de jogo;
- fundo espacial animado;
- HUD inicial;
- nave protótipo animada.

## Próxima evolução
- joystick virtual esquerdo;
- mira e disparo no lado direito;
- inimigo básico;
- projéteis;
- colisões;
- vida/escudo;
- primeira missão;
- recompensa;
- tela de resultado.
